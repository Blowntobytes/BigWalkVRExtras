# Changelog

## 1.0.0
First public release.
- AUTO SPRINT row in Settings > Big Walk VR: sprint whenever the left joystick is pushed.
- GRIP MODE row (HOLD / TOGGLE): with TOGGLE, one grip squeeze grabs and keeps the item; squeeze again and it drops when you let go.
- VIRTUAL CROUCH row (OFF / HOLD / TOGGLE): pull the right joystick back to crouch; jumping cancels a toggled crouch; the VR view is lowered while crouched.
- Right joystick click toggles sit / stand (optional hold-to-recalibrate-height in the config).
